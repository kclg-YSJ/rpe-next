RPE Next 协作服务器

为编辑器提供房间、可靠同步与 P2P 配对。保持此窗口和电脑运行。

① 启动本机服务

② 让外网用户能够连接

已有公网反向代理时可直接使用自己的 WSS 地址。没有公网入口时，可使用 Cloudflare Tunnel。

首次从 Cloudflare 官方 GitHub 发布页下载 Windows 版 cloudflared.exe，再选择该文件。临时隧道无需账号，但不保证长期可用；长期使用推荐固定域名隧道。

固定隧道（可选）

在 Cloudflare 中把域名服务指向 http://localhost:4182（端口按实际设置）。令牌不写入配置文件或日志。

③ 创建房间并邀请

编辑器 → 谱面工具 → 联机协作，填入连接地址，创建房间，再把邀请发给伙伴。伙伴只需粘贴邀请，等待房主批准。

服务只在内存中保留房间。停止服务前请让所有人保存谱面；服务器不会扫描或共享你的文件夹。
