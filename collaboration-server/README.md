## 启动 GUI

维护者使用打包目录中的 `RPE-Collaboration-Server.exe`，无需安装 Node.js；保留同目录全部文件。开发目录可双击 `start.cmd`（需编辑器已安装 Electron 和此目录的 ws 依赖）。关闭 GUI 会停止服务和由它启动的隧道。

1. 点击 **启动服务**。默认仅监听本机 4182 端口；使用公网隧道无需改动。
2. 如需局域网直连，启动前勾选允许局域网访问，并允许 Windows 防火墙对应入站连接。
3. 外网用户需要公网入口。已有反向代理时，把 WSS `/collab` 和 HTTP `/collab/media/*` 都代理到 `http://127.0.0.1:4182`，需支持 WebSocket 和带 Authorization 请求头的 HTTP 请求。Cloudflare Tunnel 直接代理此地址即可，无需另开端口。
4. 没有公网入口时，从 [Cloudflare 官方发布页](https://github.com/cloudflare/cloudflared/releases) 下载 Windows cloudflared.exe；在 GUI 选择它，再点击 **启动公网隧道**。地址出现后复制到编辑器。
5. 临时隧道地址会变化，不提供可用性保证。长期运行推荐在 Cloudflare 创建固定域名隧道，源站填 `http://localhost:4182`，在 GUI 输入该隧道的令牌。令牌不落盘，不打印到日志；同机进程管理工具仍可能看见子进程参数。
6. 编辑器中打开谱面 → 谱面工具 → 联机协作 → 输入服务器地址和昵称 → 创建房间。伙伴只需粘贴邀请，房主在联机页面批准。

本地启动器与桌面端的 HTTP 素材白名单默认包含本机和 Cloudflare 临时隧道，且仅允许 `/collab/media/` 接口。使用其他固定域名或局域网服务器时，启动编辑器前设置 `RPE_MEDIA_ORIGINS`，例如 PowerShell 中先执行 `$env:RPE_MEDIA_ORIGINS='https://collab.example.com'` 再运行编辑器启动脚本；多个源地址用逗号隔开，不含路径、密码或令牌。在线 Pages 版不受本地启动器这项白名单限制。

创建房间密钥是可选的服务器访问限制，不是参与者的邀请密码。服务启动后不能更改，停止再启动即可使用新密钥。公网长期部署建议设置密钥，并在入口施加连接/请求速率限制。

公网同步采用小分片并控制发送队列，较大的谱面不会作为单个巨大 WebSocket 消息发送。此功能需要更新服务器程序；请关闭旧版服务后启动新版 GUI，编辑器刷新到同一版再连接。

建房同步会显示发送、接收进度。有效传输会延长等待时间，不再因为上传超过 15 秒或往返超过 30 秒而断开；连续 60 秒没有进展或总时长超过 10 分钟才超时，避免失效连接一直占用服务。

发送从 16 个未确认分片起步，随有效确认逐步扩展到最多 128 个（约 1 MiB 的 ASCII 数据），同时限制 WebSocket 缓冲，避免隧道积压无限数据。进度按对端确认数显示；有效数据或确认也视为连接存活。

新客户端建房时，服务器验证谱面后只返回确认，房主使用已提交的同一份谱面，不再整份下载一遍；加入、重连仍会收到完整的最新谱面。支持的浏览器与服务器自动协商 WebSocket 压缩，对谱面 JSON 通常能显著减少流量。压缩使用有限并发且每帧重置字典，不支持压缩时自动使用原始传输。

素材使用独立的二进制 HTTP 通道：每块 1 MiB，上传和每位成员的下载均最多四路并发，不经过 WebSocket 的 JSON/Base64 编码和逐片确认队列。慢成员不会拖住房主或其他成员，也不会占住聊天和编辑同步通道。临时失败重试单块；取消接收或断线会取消本机 HTTP 任务。联机页面显示 HTTP 四路并发、进度与速率，音乐和图片不重新编码或降低品质。

当房主与服务器位于同一电脑时，新版房主会探测服务器公布的单个回环端口，使用随机挑战和 HMAC 验证确为同一服务器后，直接在本机上传素材，避免绕行公网隧道。探测不携带媒体访问令牌，失败则保持原公网路径。其他成员不会进行这种探测，仍从自己的房间公网地址下载；不要求接收者与服务器同机。素材状态会显示“本机直连”。

新版会在 HTTP 上传连续 15 秒没有接收进度或分片确认，或连接失败时，切换备用通道。服务器持续收到数据会更新进度和等待时间，单块 HTTP 请求最长五分钟。切换时先停止服务器端残留 HTTP 请求并查询已经保存的分片，仅续传缺失部分，避免两路争抢带宽和重复上传。备用通道最多同时等待两块，沿用联机分帧及确认机制；鼠标、时间和心跳等过期状态会合并，防止素材完成后集中发送数百条状态触发限流，编辑操作不合并。两种通道写入同一份临时缓存，最终仍需通过完整 SHA-256 校验，保留晚加入成员自动补收能力。此功能需要同时更新编辑器和协作服务器；旧服务器停滞时会明确提示更新。备用通道会共享编辑消息的连接，弱网时可能影响编辑同步延迟，正常网络仍优先使用独立 HTTP 上传。

“等待首个分片确认”表示已经完成本地校验和服务器准备，但尚无分片获得服务器保存确认，不代表正在计算哈希。新版双方诊断会区分服务器接收请求、接收数据、写入磁盘、保存完成及备用通道分帧确认；仅记录阶段、编号和字节数，不记录素材名、内容、地址、凭据或摘要。

房主发送后，服务器完整校验并发布最新一组素材，即使当时没有其他成员接收也可以发布。之后新成员勾选接收，会自动下载最近已发布的一组；以后新发布的组也会推送。未变更的文件按 SHA-256 复用，接收过的同名同内容文件无需重复下载，较小文件优先载入。尚未完成或校验失败的新组不会替换已发布的组。旧版本的 WebSocket 素材传输只作兼容回退，不具备自动补收能力。

服务端素材保存在运行账号的临时目录中，文件名使用摘要，不使用用户提供的路径；只允许已批准且在线的成员凭独立随机令牌访问。令牌放在 Authorization 请求头，不出现在链接或日志中。单文件最多 128 MiB，每组最多 512 MiB，全服务逻辑素材预算 2 GiB，合并校验期间会有临时文件开销。房间回收和服务正常关闭时清理；异常退出可能留下 `rpe-next-media-*` 临时目录，可在确认服务已停止后删除。缓存不跨服务重启恢复，重启后房主需重新发布。

以上优化需要编辑器和服务器同时更新。开发目录可关闭旧 GUI 后运行本目录 `start.cmd` 使用最新源码，无需重新封装编辑器。旧服务器会回退到原有的小块格式。固定 Cloudflare 隧道并不保证提速，实际速度仍受线路、时延和维护者上行带宽影响。

如果停在“已连接，正在同步”后断开，请在编辑器联机页面点击“导出联机诊断”，并在服务器 GUI 点击“打开脱敏诊断日志”。服务端日志位于 `%APPDATA%\rpe-next-server\collaboration-diagnostics.log`，每次启动 GUI 重新记录，上限 1 MiB；仅记录阶段、数据大小和断线代码，不记录谱面、媒体、昵称、地址或凭据。客户端诊断同样不包含这些内容。

## 同步与数据

- 编辑器通信层独立于协作核心。可靠操作目前使用 WSS，经服务器校验并排定顺序；远端鼠标尝试 WebRTC 数据通道，WSS 始终提供回退。
- 服务器在内存保存房间、对象锁、最近聊天和操作回执，仅将房主主动发布的素材写入隔离的临时缓存，不扫描用户目录。所有人离线 30 分钟后回收房间与素材；重启服务器会清空房间。
- 诊断日志跨启动追加，按约 1 MiB 轮换并保留最近三份历史日志。固定隧道令牌只通过子进程环境变量传递，不写入命令行、配置文件或日志；服务器仍不承担谱面持久化备份，请在客户端保存并导出 PEZ。
- 房主离线会暂停提交；客户端保留谱面并自动尝试重连。失去确认的本地操作可从联机页面导出恢复副本。不能离线产生修改再自动覆盖他人数据。
- 编辑已有音符/事件时选中即申请锁，定时续期，取消选中/断线释放。批量锁全有或全无，提交时再次校验。撤销/重做只涉及自己的操作且检查目标未被他人改动。
- 会话统计为操作涉及的物件次数，同一物件多次修改会重复计数。
- 房主主动发布当前谱面引用的音乐和图片；接收者勾选后自动接收最近发布的组。每个素材经过服务端及接收端 SHA-256 校验，并载入接收者当前项目。暂不自动传送自定义 shader 文件。
- 单帧消息上限 64 MiB，房间默认最多 12 人、20 个房间。公网直连不可达时仍能通过 WSS 联机，但服务入口必须可达。P2P 可能暴露公网 IP。
- 普通用户输入与聊天不执行代码；邀请使用随机凭据和房主批准；JSON 禁止原型污染字段，远端图片不写任意路径。公开 WSS 服务要使用可信 HTTPS 证书。初版适合可信协作者的小规模使用，尚未做互联网大规模负载审计。

## 命令行与测试

此目录运行 `npm ci` 后，`npm start` 可无 GUI 启动。环境变量：`RPE_COLLAB_PORT`、`RPE_COLLAB_HOST`、`RPE_COLLAB_KEY`。`GET /health` 只返回服务名称和协议版本，不公开房间列表。

`npm test` 运行真实 WebSocket 多客户端测试。在编辑器根目录运行 `node tools/build-collaboration-server.ts` 生成独立 Windows GUI 工具，输出位于忽略上传的 release 文件夹。

第三方组件：ws（MIT）、Electron（MIT）、可选 cloudflared（Apache-2.0，需用户自行获取）。不在此项目中分发 cloudflared 二进制文件。
