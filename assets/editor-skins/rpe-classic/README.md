# RPE Classic · 经典编辑器

基于 RPE Classic 0.2.5 内置集成。设置中选择本皮肤后自动启用同版本经典编辑布局，切换其他皮肤自动卸载布局。安全模式或手动停用模组时保留墨线回退；不改变音符皮肤和谱面数据。

配套更新随本体分发，导入包不能覆盖内置版本。后续界面适配由皮肤维护方验证。导出为标准 `.rpenskin` 时包含完整字体、图标与许可；在没有内置该皮肤的编辑器中使用时，需要同时启用同版本的 `rpe-classic-layout` 模组。

共享墨线资源仅用于内置存储去重，不改变导出格式。来自原 RPE 的素材已获项目作者确认可随本体分发，仍保留原来源与权利说明。许可见 LICENSE、LICENSE-OFL.txt、NOTICE 和 ASSETS.md。

Bundled from RPE Classic 0.2.5. Selecting this skin loads its matching layout; changing skins unloads it. Updates ship with the editor. The skin maintainer handles future visual adaptation. Portable exports include all shared resources and license notices and require the matching layout mod on hosts where it is not bundled.
