# RPE Classic · 经典编辑布局

基于 RPE Classic 0.2.5 内置集成，与同版本的 `rpe-classic` 编辑器皮肤配套。选择该皮肤会自动启用布局，切换其他皮肤会卸载；默认皮肤选择不变。安全模式或手动停用布局时使用墨线回退。Ctrl+Alt+L 可在经典和墨线布局之间临时切换，快捷键可在模组设置中修改。

内置修正：控制球使用经典布局实际缩放后的时间坐标；缓动编号草稿保留最近修改的首/尾数值记忆；共享墨线字体与图标，未选用时延迟读取。源码内置版本保留 0.2.5 标识。

配套更新随本体分发，导入包不覆盖内置版本。后续经典界面适配与外观验证由皮肤维护方完成。

皮肤及模组可分别导出为标准扩展包。重新导入到没有内置它们的编辑器时，需要同时应用皮肤并启用模组。字体和图形许可、来源见本目录 LICENSE、LICENSE-OFL.txt、NOTICE 和 ASSETS.md。来自原 RPE 的素材经项目作者确认可以随本体分发，保留其原有权利与来源说明。

This bundled integration uses RPE Classic 0.2.5. Selecting its matching editor skin automatically loads the layout; choosing another skin unloads it. Safe mode and manual disabling retain the Inkline fallback. Updates ship with the editor and imported packages do not replace bundled versions. The skin maintainer handles subsequent visual adaptation. Shared resources are restored into portable exports with their license notices.
