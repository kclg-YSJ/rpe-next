# RPEN AI Agent 与编辑器命令协议

API版本：1。谱面工具→AI辅助，首次打开后AI页签在本次谱面编辑期间常驻；进入谱面库或换谱面时保存对话、隐藏页签、停止未完成任务。配置和自定义系统提示词保存在本机；API Key默认在本机记住，可关闭“记住API Key”或清除，不进入谱面、普通配置导出、请求记录和源码索引。

## 对话与展示

消息输入框可粘贴 PNG/JPEG/WebP/GIF/AVIF 图片。每条最多 4 张，原始文件上限 20 MiB，本机将长边限制至 1600 像素并压缩为 PNG/JPEG（单张 data URL 上限 1.5 MiB）。缩略图可预览、移除；各对话分别保存图片草稿，发送后图像随该轮历史保存。重试、编辑重发、排队和插话沿用同一附件语义，不支持识图时提示并保留草稿。图片不写入谱面 JSON/PEZ，发送时作为当前 API 提供商请求内容。GIF 等动画取静态首帧。

规范化用户消息的 `content` 可为字符串，也可为 `[{type:'text',text}, {type:'image_url',image_url:{url:'data:image/…;base64,…',detail:'auto'}}]`；Provider 必须保留此结构并自行适配其 API，不能转成 `[object Object]` 或静默忽略。本轮新粘贴图像优先保留，较旧截图继续按图像数量/体积预算移出请求；历史展示仍保留原附件，压缩摘要不包含 base64。`capabilities(model).images` 声明图像能力，`modelInfo` 可根据 `architecture.input_modalities` 覆盖。`EditorAgent.run(text,{images})` 与 `steer(text,images)` 接受经验证的本地 data URL 附件；内部 `rpen_input_images` 标记不进入 API 请求体。

每个谱面可创建、切换、重命名和删除多个对话，关闭、保存重开或重启应用后恢复。各对话有独立消息、草稿和上下文范围：默认全部历史，可选择最近N轮或仅本次消息；一轮指用户请求及其全部模型/工具/回答，截取不拆断工具调用配对。切换或新建对话不取消另一对话正在进行的任务；后台任务有返回入口，审批/追问保留在所属对话中。为避免并行改谱，只运行一个任务，可从任意对话停止它。对话属于本地谱面工作区，不写入谱面 JSON 或 PEZ。

用户消息和最终答复直接呈现，可通过各自的小标题折叠；工作过程结束后自动折叠，内部按顺序展示思考与工具调用，不再另套模型回复层级。模型返回的reasoning_content默认显示为单行思考预览，超出宽度用省略号截断，点击后展开全文，流式到达时更新；未返回时不生成或冒充思考。答复支持标题、列表、表格、引用、代码块与复制、强调和安全链接；原始HTML作为文本，脚本/本地文件链接和远程图片自动加载不被允许。

历史消息可编辑重发，回复可重试；两者均留在原对话中，替换该轮并丢弃之后的消息，不新建对话。对话名称、标识与上下文范围保持不变；仅保留该轮之前的完整消息，覆盖被丢弃消息的压缩摘要同时失效，用量重新估算，保存重开后也不恢复旧消息。已执行的谱面修改不自动撤销，因此提示词要求先重读当前谱面、防止重复生成，正常审批仍生效。每轮小字显示实际模型、开始时间、总用时、输入/输出/总tokens、可用的思考/缓存tokens、请求和工具次数；单次模型请求也有用时/用量。用量来自API返回，未提供时明确显示“用量未返回”，不伪造估计。总用时含用户等待，悬停可见模型请求用时。

顶部两行紧凑排列对话管理、配置、上下文与权限，聊天内容占满剩余高度；“折叠全部”和“展开全部”位于管理菜单。发送按钮在输入框右下方；运行时可继续排队发送，提供插话和停止，窄面板自动换行。默认单次输出上限65536，旧内置8192默认值升级为65536，其他自定义上限保留。模型配置与审批模式仍为共享设置，各对话的上下文范围独立，修改在下次发送时生效。

配置中的“面板字号（px）”默认14，可设置10–24的整数。应用后正文、思考、操作控件和小字随之调整；字号沿用本机偏好存储，重启后恢复，不写入谱面。

“每任务最大模型请求轮数”默认128，可设置1–4096，限制一次用户任务调用模型的轮数，每轮可包含多个工具调用，最终答复也计一轮，与单次输出tokens上限无关。达到上限停止本次任务并保留已完成修改，可继续发送消息。旧默认24升级为128，自定义值保留。

进行中和结束后的任务用时、单次请求用时均使用同一个单调时钟，不受系统时钟校准影响。开始时间仍使用本地日历时间；整轮用时含工具执行、等待批准和等待回答，不以累计tokens或多轮请求用时冒充整轮时长。

“记住API Key”默认开启，应用配置时单独保存各服务的Key，启动后自动恢复。桌面端使用系统加密服务，密文保存在固定用户数据目录的`agent-credentials.json`，更新或移动程序仍继承，不随谱面库打包或备份；系统无法提供加密时提示失败，可选择仅本次使用。网页端使用当前站点独立的IndexedDB凭据库，不混入可导出的普通设置。取消勾选并应用会删除当前服务已保存的Key，但本次仍可使用所填值；“清除已保存的Key”同时清除当前输入和内存值。关闭配置而未应用不会保存输入的Key。

提问选项按可用宽度自动排列，长文字在按钮内换行，支持窄面板和较大字号。提示词与`ask_user`参数说明要求通常提供2–4个清晰简短、每项一个选择的选项；详细解释放在问题正文，也可仅让用户自由输入。

对话停留在底部时，流式输出和工具记录自动跟随；用户向上翻看后停止跟随，向下回到底部附近再恢复，发送新消息也会转到最新位置。每个对话分别保留本次会话的滚动位置和跟随状态，后台任务的输出不会拉动当前查看的其他对话。

## 持久化、请求记录与任务队列

对话以本地谱面的稳定工作区标识隔离。首次保存前后的标识保持一致；保存重开、从谱面库恢复编辑或完整重启后，恢复多个对话、选中项、草稿、独立上下文和压缩记忆。网页端使用谱面库 IndexedDB 的独立记录；桌面端使用原生库的 `preferences` 记录，更新程序不丢失。对话元数据、轮次、压缩记忆、原始请求分别保存；快速退出重进会等待旧写入，旧任务的迟到收尾只更新所属轮次。关闭应用会停止任务并等待保存。恢复的未完成任务标记为停止，待执行队列需用户点击继续，不自行运行。

每轮右上角的小按钮打开独立请求检查窗口，可切换该轮的模型请求和压缩请求，查看实际序列化的完整请求体、原始 SSE 返回、失败或中断内容，并复制；按需读取，不在普通聊天布局中展开，也不按五万字符截断。Authorization 与当前 API Key 被隐藏。Provider 可实现 `onTrace({request?,response?})` 记录实际传输格式；未实现时保留规范化请求/返回，不将其伪装为原始 HTTP 报文。

任务运行时输入框可继续使用，默认加入队列；队列按提交顺序逐个执行，各任务使用所属对话的上下文，未执行的消息不会提前发给模型。可取消排队，或将同一对话的排队消息提升为插话。插话仅显示在所属任务的工作过程中，接收前标记待发送，不在对话底部重复放置；用户消息采用独立配色。插话中断未完成的模型响应，在正在执行的操作完成或取消后重新规划；跳过未执行的旧调用，并补齐工具返回，保持调用配对。已完成的修改保留。停止或失败会暂停剩余队列；从其他对话排队不切断当前任务。提问、审批等待和任务完成通过编辑器左上角非阻断通知提示，短通知按内容收缩。

## 上下文压缩与请求开销

配置中的“自动压缩上下文”默认开启。自动阈值取当前模型上下文长度的65%，同时为最大输出与协议开销预留空间；优先读取Provider的`modelInfo(config,{signal})`元信息，DeepSeek通过`GET /models`读取`context_window`，成功缓存一小时。缺少长度或请求失败时，DeepSeek按1M（1048576 tokens）计算。可切换自定义阈值；旧默认131072升级为自动模式，已有自定义值保留。关闭自动压缩后，不在达到阈值或接口超限时擅自压缩；手动“压缩”仍可用。

“压缩”右侧显示上下文圆环及数字、百分比，不增加额外标签。比例的分母为模型完整上下文长度；用量优先使用最近一次接口返回的输入加输出tokens，不使用多轮累计计费量。请求前、上下文范围或提示词变化后采用本地估算，悬停说明来源、完整数字和实际压缩阈值；各对话独立，切换时同步。`.agent-context-usage`、`.agent-context-ring`和`.agent-context-number`分别对应整体、圆环和数字。

也可点击上下文旁的“压缩”。截取遵守完整工具调用组。过长历史分片归纳为目标、约束、已完成操作、精确标识/数值和待办，保留近期上下文与最新用户要求；压缩后继续原对话，完整历史和原始请求仍可查看。开启自动压缩且遇到接口上下文超限时，降低预算并尝试压缩重试，不重放已完成编辑。

初始请求仅携带常用命令定义，`agent_tools` 按用途、中文关键词或 `names` 查找全部注册命令，结果中的命令在后续请求激活完整参数定义，模组命令也适用。初始工作区摘要限制命名实体和选区样本，详细数据按需查询。已完成最终答复的思考不反复发送，思考工具协议要求的字段保留；旧大型工具结果缩短，当前数据重新读取。历史图像最多保留近期两张且受容量限制，不支持识图的模型收到文字占位。自定义系统提示词不被偷偷截断。

## 脚本、组件与文件工作区

`chart_script({revision,source,input?,label?,dryRun?,timeoutMs?})` 在独立模块 Worker 执行 JavaScript。`chart` 是完整谱面副本，可用循环、函数和任意算法修改所有合法 JSON 字段，包括音符、事件、判定线、噪域、全局事件和模组数据；`api` 提供 `createNote/createEvent/createLine/createNoiseArea/createNoiseEvent/fromNumber/beatValue/parseBeat/easing/clone/report`。默认采用修改后的 `chart`，可 `return {chart,result}` 返回另一份谱面及简短统计。默认超时10秒，可设100–30000毫秒。`dryRun` 只计算并展示计划；实际执行在宿主验证、修订检查及审批后一次提交，可撤销重做。整线删除/重排、根字段丢失、大量删除、音乐/背景引用变化属于危险操作，计划中展示完整脚本和统计。

Worker 只与宿主交换数据，不提供 DOM、Node、凭据、网络、IndexedDB 或工作区接口，并禁用全局及原型链上的相关入口；停止/超时终止 Worker，失败不应用部分谱面。读写文件或操作界面分别使用对应命令。直接脚本改线序时仍须正确处理父线与引用；通常优先 `line_manage`。

`editor_api` 提供原生组件的通用后备入口：`describe` 查询可用目标及现有成员，`get` 读取数据属性，核查源码后 `call` 方法或 `set` 现有可写属性。范围包括时间轴、预览、判定线面板、音频、噪域、全局事件、拟合工具、皮肤和版本等。调用/修改统一按危险操作审批，沿用原生方法的保存、撤销及取消行为，不承诺通用事务回滚；优先使用结构化命令。参数中的 `{$workspaceFile:"相对路径",name:"文件名"}` 在本机解析为 File，可传给原生导入方法，不把二进制文件发给模型。构造器、原型入口、凭据与 Agent 自身不开放。

文件工具：

| 命令 | 功能 |
| --- | --- |
| `workspace_files` | `info/list/read/write/mkdir/move/delete`；相对路径，文本/base64与分页，覆盖需 `overwrite` |
| `workspace_download` | 从公开HTTP/HTTPS下载到工作区，大小上限128MiB，桌面端流式写临时文件后替换，重定向逐跳检查 |
| `workspace_import_asset` | 将工作区文件复制为谱面素材，`binding=song/background`可绑定；需要保存，不把二进制发给模型 |

桌面文件位于固定用户数据目录 `agent-workspaces/<工作区哈希>`，AI面板“工作区”按钮打开本谱面的实际文件夹；网页端使用当前站点的持久记录，下载受CORS限制。工作区文件不自动写入谱面、PEZ或谱面库外部备份；需要携带时导入为素材或自行备份。路径不可越界、访问绝对路径或符号链接；覆盖前核对文件指纹，网页批量写入采用事务及冲突检查。新建普通文件为普通编辑，覆盖/删除/可执行文件、下载和导入素材按危险操作处理。完整访问模式仍受浏览器/系统固有授权和工作区边界限制；不提供任意磁盘或终端执行接口。

`editor.agent.ready` 等待凭据和当前谱面对话载入，`await editor.agent.flush()` 等待对话与请求记录落盘；`editor.agent.workspace` 提供同一工作区的宿主接口，供可信扩展使用。

## 架构

- `src/application/agent.mjs`：通用模型/工具循环、消息、轮次、停止和失败恢复。
- `src/application/agent-conversations.mjs`：对话、历史截断、完整轮次上下文选择；`src/ui/agent-dialogues.mjs`管理展示与交互，`src/ui/agent-markdown.mjs`通过DOM构建安全Markdown。
- `src/platform/agent-store.mjs`：分谱面与分轮次持久化；`src/core/agent-context.mjs`：压缩与上下文策略；`src/ui/agent-inspector.mjs`：完整请求检查。
- `src/core/agent-commands.mjs`：命令注册、JSON参数校验、计划、审批、执行。
- `src/application/agent-editor.mjs`：编辑器适配，不使模型持有编辑器实例。
- `src/application/agent-chart-tools.mjs`：谱面工具目录与原生生成器适配；`src/application/agent-workspace-tools.mjs`：多媒体视图、音频处理及版本控制命令。
- `src/application/agent-scripting-tools.mjs`、`agent-component-tools.mjs`、`agent-file-tools.mjs`：通用脚本、组件与文件命令；`src/platform/agent-script-worker.mjs`负责隔离计算，`desktop/agent-workspace.mjs`负责桌面文件操作。
- `src/core/agent-source.mjs`、`src/platform/agent-source.mjs`：当前构建源码的只读索引、搜索与分页读取；`desktop/agent-source.mjs`收集程序源码，网站构建与桌面端共用。
- `src/platform/agent-provider.mjs`：Provider注册和API格式/能力/流式适配。
- `src/ui/agent-panel.mjs`：配置、聊天、具体审批和用户回答。

这里不是自然语言关键词匹配器。模型每轮可选择任意注册工具，读取结果后继续，直到完成、停止或达到上限。振动、圆周、采音只是便捷命令；任意其他任务可通过通用查询、修改、批量表达式、生成模板和控件操作组合完成。绘制循环不轮询整个谱面或执行AI逻辑。

## 权限

| 模式 | 只读 | 普通编辑 | 关键操作 |
| --- | --- | --- | --- |
| ask 请求批准（默认） | 自动 | 每次批准 | 每次批准 |
| dangerous 危险操作批准 | 自动 | 自动 | 每次批准 |
| full 完全访问权限 | 自动 | 自动 | 自动 |

关键操作包括删除整条线、替换整张谱面/整条线、批量删除大量物件、覆盖生成区间旧事件、素材写入替换删除和保存。UI中的普通字段设置/导航按普通编辑处理；未知控件和快捷键可触发插件行为，按关键操作分级。完整访问只免除编辑器命令审批，不赋予终端、任意磁盘、跨域或系统权限，系统文件选择器仍由用户选择文件。

prepare只读地生成确定计划，apply才执行。审批显示摘要与具体参数/变更，单次批准或拒绝。拒绝返回denied，提示词禁止改名或换工具绕过。revision是当前不可变谱面对象的修订标识；修改命令要求最近读取的revision，审批期间谱面变化、换谱面、停止或命令卸载后旧计划失效。工具串行运行。普通谱面修改经原有session.commit，一次撤销重做，沿用联机提交。素材修改沿用原生替换流程，明确标为不可用普通撤销恢复且需要保存。停止不会回滚已执行操作。

`diagnose` 等待后台基础检查，并合并用户已经完成且仍有效的深度结果，支持分页读取；它不会自行启动耗时的深度检查。需要判定位置、可读时间、Flick/Drag 后接 Tap、间接素材依赖或模组自定义规则时，先说明用途，再由用户主动点击检查面板的“手动深度检查”。`code/severity/path/line/layer/index` 提供定位信息，`globalType/globalColumn` 标识全局事件，`asset` 标识素材引用；`target` 标识所选的导出兼容目标。深度结果随谱面、素材、模组或比例变化失效，不能沿用旧索引进行编辑。

通用chart工具可读取/编辑未知扩展字段、模组结构、所有音符事件、噪域层/皮肤及全局事件，不限内置例子。所有修改先在副本验证成功再一次提交；保留不相关字段；特殊JSON键按自有数据处理，不遍历原型链。透明度沿用原生取整规则。删线优先使用line_manage维护父线与着色器引用。

调速曲线面板的操作调整所选音符所属线的 `speedEvents`，不调整音符 `speed`。节点的“后段缓动”直接描述到下一个同层节点（包括面板默认判定点）的距离曲线，恒速距离是缓动 1；例如缓动 5 的二次距离由线性速度事件实现。切换缓动固定两端距离，优先使用原生单事件，必要时每段距离曲线最多用 64 个正时长速度事件拟合，误差容限为 max(0.2, 两端距离差绝对值 × 0.0015)。默认判定锚点不可移动或删除，但允许真实速度节点添加或移动到该位置，重合时优先选择真实节点，可修改拍数、后段缓动、拖出或删除；该时刻的距离仍由音符偏移约束。从判定前移入节点只重建前段，保留判定后速度；继续编辑前段不会带动后段。删除重合节点时保持两侧端点距离，默认锚点继续存在。末节点禁用缓动。`rpeNextSpeedCurveNode: true` 与 `rpeNextSpeedCurveEndNode: true` 是可选的起点/终点编辑标记。`rpeNextDistanceCurve` 是可选的版本 1 面板分组记录（id、start/end 拍数、easing、count 和 native 形状签名），有效完整分组的内部拟合接点在面板中隐藏；外部编辑形状或拆散分组后重新识别。它们均不参与播放器求值或积分。通过通用事件读写工具处理速度事件时保留这些字段及其他未知字段；修改会影响该判定线上的所有相关音符。面板视图与吸附设置保存在本地偏好中，不写入谱面。

音符`judgeArea`是独立于`size`的判定区域倍率，默认1；`tint`是RGB音符颜色，默认`[255,255,255]`；`tintHitEffects`是RGB特效颜色，默认`[255,236,160]`；自定义打击音效引用使用RPE的`hitsound`字段，空值或省略采用默认音效，`hitSound`仅兼容旧数据。音频素材不因被选中、试听或作为音符音效而替换谱面音乐，移动素材应同步引用。`META.song`和`META.background`的显式空值表示未绑定媒体，删除引用音符后仍保持未绑定；本地保存保留闲置素材，导出按“包含未使用文件”统一筛选音频与图片。多线表达式中，`all`表示全部线，`@notes`表示当前时间视野有音符的线，`@events`表示当前层在该视野有事件的线（均不区分大小写）。空格分隔词元取并集，例如`0 @notes @events`；动态表达式由`multi_line`命令保留并随播放、跳转和编辑刷新，空结果保持多线模式。三个词元均不能作为判定线组名。

`chart_tools`覆盖谱面信息、BPM、素材、波形频谱、噪域编辑、曲线音符、曲线轨迹、文字拼合、噪域图案、噪域追踪、多线编辑、全局事件、检查、历史和版本控制。生成命令直接复用原生计算函数，不通过点击隐藏面板伪装生成；文字和噪域图案与手动工具共用光栅化、后台拟合Worker及结果写入逻辑，停止时终止Worker。`text_fit`与`noise_fit`的`analyzeOnly=true`只返回数量/误差，不修改谱面、不需要编辑批准。拟合不达标返回`generated:false`，不能报告已生成。轨迹/曲线音符使用目标线局部拍，噪域图案与追踪使用全局拍。普通生成一次撤销，覆盖已有事件要求关键批准；生成不强制切换页面或当前时间。

`trajectory_generate`通过`preset`按id或名称选用预设，`options`覆盖参数方程、极坐标、数值参数字典、截取、旋转、缩放、对齐、XY缓动或切线旋转；`output=trajectory`保留整体轨迹，`output=events`直接拆分。例如`{revision, line:0, layer:1, start:8, end:12, options:{xExpression:"200*cos(2*pi*t)", yExpression:"80*sin(2*pi*t)"}}`生成椭圆轨迹。`eventIndex`可更新该线该层已有整体轨迹，`trajectory_split`按原生段数与简化容忍度拆分。已有冲突默认拒绝，`replace`不会自动开启。

`version_control`的查询不自动初始化或提交版本。初始化、提交及删除引用属于关键操作，暂存/取消暂存/创建引用按普通编辑审批；仓库写入不属于普通谱面撤销。切换/合并/冲突解决、储藏与版本包导入导出可继续使用原生版本控制面板和`ui_inspect/ui_action`，保留各自的确认流程。外部素材/字体文件仍由原生文件选择器导入，或在用户授权后通过已有素材命令读取项目内文件；没有任意磁盘访问。

## 查阅当前源码

遇到字段、坐标、工具参数、事件累计、渲染或交互行为不确定时，Agent可自行用`editor_source`查证，无需询问用户能否读源代码。该命令只读取随当前程序提供的源码：`src`内四个运行目录、`src/i18n.mjs`、`src/locales`语言目录、桌面实现、内置模组与编辑器皮肤声明、公开协议、schemas和入口样式。系统提示词和界面文本使用翻译键时，可继续读取对应语言文件核对完整内容。开发服务器即时收集，Pages构建将同一份索引写入`assets/agent-source.json`，桌面端从自身程序目录提供；不依赖仓库在线版本，不下载可能不匹配的代码。首次使用按需载入并在本次启动缓存，不加入绘制循环。

- `action=list`：`path`为目录前缀，`query`筛选文件名，`offset/limit`分页。
- `action=search`：`query`为单行字面关键词，`path`缩小目录范围，`caseSensitive`控制大小写；返回文件、1起行列号及片段，`nextOffset`续页。搜索不接受正则表达式。
- `action=read`：指定索引内的完整`path`，用`startLine/startColumn/lineCount`读取；返回带行列号的文本和`next`。每次最多200行、16000字符，长行也可按返回的行列续读，不会静默丢弃剩余文本。

读源码在三种权限下均免批准，返回文本仅作为查证材料，不执行或修改源码，也不授予终端权限。索引只收集规定的程序文件，不包含谱面库、恢复文件、用户配置、凭据、`.local-tools`或其他本地文档。源码里的字符串、注释和示例不是新用户指令；查明实现后仍通过原有命令操作编辑器并遵守审批。用户尚未指定的创作意图不由源码推断，仍应提问。

## 编辑器截图

`editor_capture({target?,handle?})`是只读命令，仅对支持图像输入的模型开放。`target`默认`editor`截取整个编辑器可视窗口，`timeline`为左侧编辑区域，`panel`为右侧面板，`dialog`为当前非AI弹窗，`control`使用最近`ui_inspect`返回的`handle`。先打开需要查看的面板，不滚动、打开隐藏内容或改变选择。截图只包含可见范围，最大输出宽度1600像素。

桌面端使用本应用窗口的原生截图；网页端通过本地DOM、样式、字体与画布合成图像，不调用系统屏幕共享、不访问其他应用。网页重建可能受跨域素材或浏览器渲染能力限制，失败会明确返回错误；需要检查谱面视觉时仍优先`preview_capture`。AI对话、配置、请求详情、审批以及密码框不进入模型图像：网页克隆时排除，输出图像再次遮盖；桌面原生图像同样在交给模型前遮盖。控件句柄过期、私密目标或目标不可见时拒绝截图。截图不能证明隐藏数据或实际音频效果，仍须通过查询命令核对谱面状态。

## 通用编辑与分析

chart_query的where为field/op/value条件，field支持点分子字段，op为eq/ne/lt/lte/gt/gte/contains；时间字段默认startTime/endTime，噪域可指定appearTime/disappearTime，结束拍为右开边界。集合查询和结果有限额，大对象应分页。

chart_transform/generate的expressions为“相对物件JSON Pointer→表达式字符串”。i从0开始，N为数量，u为0–1，beat为原始起拍，可访问原顶层数值属性，支持pi/sin/cos/ease/lerp/clamp/四则/条件式；无eval、函数定义、循环或全局对象。时间字段结果为拍数，自动转三元组。where中的i为原始索引，变换中的i为被选中集合中的序号。所有字段从同一原物件求值，字段间没有隐式依赖。例如基于Tap模板生成64项，表达式 `/startTime: 40+i/8`、`/endTime: 40+i/8`、`/positionX: 250*sin(u*pi*2)` 可以生成一段任意轨迹；同样机制可构造未预设的视觉图案。

ui_inspect提供临时句柄，操作后重新读取；过期、隐藏、禁用、只读、非法值不应用。password/file/hidden输入、Agent面板/配置和审批按钮不可访问；不读取剪贴板或其他应用。UI操作成功表示交互已分发，模型仍需核对最终状态。外部素材通过原生文件选择器导入。

音频分析采用分声道功率合成的STFT、多频带白化频谱正向变化、邻带抑制、局部中位数/MAD自适应门限、置信度筛选、强峰优先最小间隔去重，以及2ms能量包络辅助起音校正，避免反相声道抵消。最长180秒，定期让出主线程、支持取消和按音频/参数缓存。focus可选all/percussion/low/melody，minConfidence默认0.35；输出频谱起音、强度、置信度和频带。默认adaptive量化仅吸附接近网格的起音，nearest严格量化，none保留实测时间；重复拍点和同位置真实Hold的身体/端点占用会跳过。起音检测不是人工听辨或音高转写，复杂复音与半速/倍速需要检查。分析只在本机进行。

## 声部分离与分析音源

谱面工具的“音频分析”将声部与分析音源、波形/频谱、采音与节奏生成列为独立功能。音源采用多选框，至少一项：实际播放与默认AI分析均使用当前混合，波形/频谱按各声部颜色并排显示。播放、定位、暂停继续、音量、倍速与保调共用原有播放时钟；原音乐数据与素材文件不变。去掉独立试听和声部起点，所有音源从原音乐零点开始并共用谱面META延迟。勾选及列表属于本次打开谱面的会话，退出谱面或更换音乐后恢复原音频；派生缓存独立保存，不随谱面导出。

桌面端可一键准备或选择Demucs 4.1环境。一键入口在原生确认后自动下载经固定哈希校验的引导工具及私有Python 3.12，建立独立环境，安装CPU或NVIDIA版PyTorch、`demucs==4.1.0`与NumPy，不修改系统Python、PATH或注册表。当前一键依赖组合面向Windows x64、Apple芯片macOS和Linux x64；其他架构显示已有环境/导入流程，不启动无法完成的自动安装。高级设置保留选择已有环境、用已有Python 3.10–3.12安装和重新检测。安装检查通过后才切换配置，失败保留已有配置；可取消与重试。依赖和模型按需下载，不包含在桌面程序包中。CUDA取决于所选环境和驱动，自动模式在CUDA不可用时使用CPU。面板内“使用指南”与[平台操作说明](AUDIO-SEPARATION.zh-CN.md)给出网页导入和故障处理。内置模型入口：

| model | 声部 |
| --- | --- |
| htdemucs | vocals人声、drums鼓、bass贝斯、other其他配器 |
| htdemucs_6s | 上述四类及guitar吉他、piano钢琴；六声部为实验效果，钢琴尤其可能串音 |

这不是任意配器或单一乐器保证分离，`other`仍可能混合多个乐器。用户需要其他模型时可使用UVR等成熟工具，再导入结果；网页端支持此导入流程，不能直接启动本机Python。分离音频和推理均在本机，只有依赖/模型下载联网，PCM不发送到AI服务。

`audio_sources`列出id、名称、时长、起点、模型与当前选择，`status=true`检测分离环境。`audio_separate({model,device,shifts})`生成当前音乐的声部并返回id，读取和计算属于只读命令，不改谱面；环境安装需要用户在桌面文件选择器与原生确认框操作。停止Agent或更换音乐会取消原生分离子进程，未完成结果不加入声部列表。结果按输入PCM哈希、模型与计算参数缓存，相同输入再次分离复用磁盘缓存；损坏缓存重新计算。仅选中的声部按需读取与解码，分片传输，避免一次将全部大音频塞进IPC；重启后再次分离也可复用缓存。清理结果缓存保留模型。模型和推理在绘制循环外运行。

`audio_sources`返回每项的id、颜色、勾选状态和当前`selection`数组。`audio_source({action:"select",source})`选择单个，或`audio_source({action:"select",sources:[id1,id2]})`同时勾选多个；`remove`用单个source移除。删除选中项时保留其他选中项，最后一项被移除时回到原音频。不再提供align或独立偏移。`audio_analyze/audio_taps`的source仍可指定完整id或唯一声部别名；不填或填selection使用当前勾选的混合，original始终分析原音乐。显式分析某项不会改变当前播放选择。指定配器前先确认或分离，focus只是频谱权重。

声部秒与原音乐秒相同，兼容输出中的offsetSeconds固定为0。谱面秒=原音乐秒−META.offset/1000，再用TempoMap与目标线bpmfactor得到局部拍。播放及混合分析始终保留原音乐采样率、时长与零点：短音源结尾补零，超出原时长的部分截断；多源逐采样相加，仅在超出峰值上限时整体降增益。单个显式声部的分析也按原时长补齐。peaks.seconds为原音乐秒，peaks.beat为目标线局部拍，各时间转换只应用一次。审批期间更换原音乐、音源选择或移除声部会使旧计划失效。

混音缓存以声部集合及原音源身份为依据，勾选顺序不同不会重复混音；近期混合和PCM媒体准备按容量及最近使用情况淘汰。更换音乐、退出谱面清理会话缓存，重新分离或移除声部使相关结果失效。缓存只改变计算和切换开销，不改变谱面延迟、混音增益规则、分析结果或审批有效性。波形/频谱复用静止画面，并针对窗口、视区、播放时间、显示参数与皮肤变化刷新；不会通过跳采样或降可见分辨率提高帧率。

## 学习型起音检测

“音频分析 → 采音与节奏生成”提供 Mapperatorinator、DDC、原频谱算法选择，以及当前播放头起10秒的候选预览。设置在本机持久化，候选不进入谱面；AI 生成仍走审批与一次撤销。新增桌面配置默认 `mapper`，网页默认 `flux`，已有选择保留。环境不可用会明确报错，不静默更换算法。在本机环境面板可检测、选择已有 Python，或创建独立环境，不改系统 Python。运行库与模型不随谱面导出或程序包分发。

`audio_detector({status:true,detector?})`查询所选环境；`audio_analyze/audio_taps`的`detector`可显式选`mapper`/`ddc`/`flux`，不填继承面板选择。`minConfidence`仅用于DDC/flux：DDC为原始起音显著性的门限（默认0.15，0–1，越低越密），不是校准后的正确概率；flux默认0.35，不同算法的分数不可直接比较。`minGap`为候选最小间隔（DDC/flux默认0.08秒，Mapper默认0.02秒，范围0.02–2秒）。`focus`、`sensitivity`仅供`flux`使用，学习型模型应省略`focus`或设为`all`，配器选择通过`source`完成。

DDC 使用100Hz时间分辨率，输入带前后上下文，按固定时间网格分块推理；不对检测时间再次施加经验性偏移。重采样、谱面延迟、线倍率、量化各只处理一次。立体声混合严重相消时使用能量最高的声道，避免反相信号被抵消。仅所需区间上传到本机进程，PCM不经过AI接口。原始显著性按输入PCM、采样率、固定模型修订与检测实现版本缓存，门限/最小间隔变化可重筛选，无需再次推理；可取消并清理结果缓存，模型保留。音乐变化会取消任务，旧审批和预览不能应用到新音源。

结果中的`method`区分`ddc-onset-cnn`与`local-multiband-spectral-flux`，`model`给出版本、修订、帧率与实际设备；`cacheHit`指明原始模型结果是否复用。`peaks`仍遵循上面的时间基准。BPM由显著性自相关给出候选，并非独立节拍跟踪结果，不能仅凭此自动改BPM。DDC不输出音高、乐器种类或人工谱面手法，不应将候选计数当作准确率。可在同一声部与区间显式选择两种算法对比。

### Mapperatorinator 节奏草稿

`mapper`直接调用固定版本 Mapperatorinator 的预训练模型与原生 `Preprocessor → Processor → MAP` 流程，根据音频和条件生成音符时间，不把 `TIMING` 的节拍/小节/BPM事件作为音符。支持参数：

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| mapperModel | v32 | 完整模型；v32-mini为轻量模型 |
| mapperMode | 3 | 3参考四键节奏，0参考点击节奏；不导入osu!坐标与键位 |
| difficulty | 5 | 0.1–15的参考osu!星级，影响模型的节奏密度，不代表Phigros定数 |
| seed | 0 | 0–4294967295的固定随机种子 |
| useChartTiming | true | 参考谱面现有BPM与相位；关闭时由基础模型推断时序，不改谱面BPM |

通常先用`source="original"`，模型是在完整音乐上学习落点选择的。用户明确指定某配器时也可分析声部，但不能将草稿描述为逐声部或音高转写。Mapper不输出逐起音置信度，界面不显示起音门限，`minConfidence`不参与筛选；不要通过虚构概率调整密度。仅提取circle、slider/hold等物件的按下时刻，忽略尾部、滑条锚点、节拍、速度与坐标事件。同一时间的多个键合并为一个Tap候选，以`multiplicity`记录原数量；结果中的`strength=1`仅满足通用量化排序接口，不是模型评分。

`method="mapperatorinator-rhythm-draft"`区分节奏草稿与起音检测；`model`记录模型/源码修订、参考模式、难度、种子、实际设备、是否采用谱面时序，`statistics`记录原始音符数量和合并后落点数。参数、BPM/相位、音源与片段均参与缓存身份；最小间隔可复用原始结果。先分析后生成应保持这些参数一致。Tap生成仍经过原生重复/Hold占用检查、审批和一次撤销，不复制osu!谱面结构。

输入保留前后各16秒上下文，并保留片段在完整音源中的时间位置与总时长，供滑窗和歌曲位置条件使用。谱面BPM先转成音源绝对秒上下文，包含META延迟，声部与原音乐共用零点，**不**把判定线倍率乘进BPM；输出时间再由共用路径映射到目标线局部拍。模型的时序重吸附只发生一次，后续RPEN量化由`quantization`明确控制。更换音乐、勾选音源或修改BPM/相位后重新分析，旧审批不能写入新状态。

环境安装下载固定版本的Mapperatorinator源码、谱面解析库和推理依赖，不安装网页界面或训练工具；Python 3.10–3.12可用。CPU与NVIDIA加速分开选择，自动设备可选择CUDA/MPS/CPU。首次运行按所选模型和参考模式下载对应权重，结果和模型位于本机独立目录；网络仅用于依赖/源码/权重下载，音频不上传。自备环境需要同时选择Python和匹配的源码根目录。外部源码和模型的MIT许可保留在下载目录中。

## 命令扩展

可信应用代码通过editor.agent.commands.register注册；模组使用api.agent.register，卸载自动注销。最终命令名为mod_加模组ID（横线/点转下划线）加本地名，本地名只用小写字母数字下划线，完整名不超过64字符。

```js
api.agent.register({
  name: 'describe_palette',
  description: '读取本模组配色',
  access: 'read',
  parameters: {type: 'object', properties: {}, additionalProperties: false},
  prepare: async (args, {signal}) => ({
    summary: '读取配色',
    apply: () => ({colors: ['#fff', '#222']})
  })
});
```

修改命令如实声明access为edit或dangerous，prepare只读，返回summary/details/valid/apply；valid为执行前的一致性检查，apply({signal})执行并返回可序列化结果。计划可升为dangerous，不能降级注册为dangerous的权限。不要返回函数、DOM、编辑器实例、API Key或无限大小结果。该扩展沿用可信模组环境，不是对恶意模组的隔离沙箱；不需要改Agent循环即可添加任何领域功能。

## Provider与网络

“新增方案”先打开模板选择窗口，选择服务或自定义模板后预填新方案；模板列表不常驻在配置表单中。关闭模板窗口不新增方案，预填项仍可修改，应用配置后才持久保存。

editor.agent.providers.register接收id/name/defaultModel/models/capabilities/complete及可选search/fetch/modelInfo。complete({config,system,messages,tools,signal,onText,onReasoning,onTrace,exchangeId})返回Chat风格assistant消息，含可选tool_calls/reasoning_content；capabilities可提供contextWindow参与预算。可选异步modelInfo(config,{signal})返回含contextWindow的对象，优先使用服务提供的实际长度；必须遵守取消、缓存与凭据隔离规则，失败采用能力声明或服务默认值，不阻断正常任务。Provider负责各家API格式、参数、能力、流式与实际请求记录适配，命令、权限、UI保持独立。

内置路由预设包括DeepSeek、OpenRouter、OpenAI、SiliconFlow、阿里云百炼/Qwen和Moonshot/Kimi，及自定义OpenAI兼容接口。配置方案各自保存名称、Provider、Base URL、模型、推理参数格式、强度、单次输出上限、压缩阈值和是否记住Key；同一Provider可有多个方案。配置窗口可新增、复制、重命名和删除方案，修改与删除在应用后生效，取消保留原配置。发送按钮左侧将模型短名与推理档位合为一个紧凑入口，不显示路由前缀、提供商名称或“推理强度”前缀；点击后在浮动面板调整方案、模型及强度，立即保存到本机，退出谱面或重启恢复；运行中锁定切换，整轮任务使用启动时的配置。权限、提示词、字号和每任务请求轮数仍共享。Key以方案id独立保存，复制方案后亦独立修改；旧DeepSeek方案保留`deepseek`凭据id，升级不要求重新输入。模组注册的Provider也可创建方案，原注册接口保持不变。

DeepSeek当前模型通过`thinking.type`控制思考开关，通过`reasoning_effort`发送`low/high/max`，默认强度为`high`；界面显示“模型默认（高）”，不会发送映射后等价的重复档位。旧模型只显示其支持的开关。OpenRouter使用`reasoning.effort`，并优先根据`GET /models`的`reasoning.supported_efforts`和`mandatory`限制选项；还读取上下文长度、输入模态及输出上限。OpenAI兼容路由依选定格式发送`reasoning_effort`、`thinking.type`或`enable_thinking`，OpenAI输出上限使用`max_completion_tokens`。仅支持开关的模型不伪装成支持多档强度；自定义服务可在“接口兼容设置”选择参数格式，`none`不发送推理参数。模型ID可手填，也可获取服务的模型列表；实际模型可用性、工具和推理档位仍由服务决定。

内置适配器使用`/chat/completions`的SSE流式返回及`stream_options.include_usage`，完整响应结束才执行本轮工具；保留工具循环必需的`reasoning_content`，OpenRouter额外原样保留返回的`reasoning_details`序列，并通过`onReasoning`向界面发出服务实际返回的文本。不合成未返回的推理过程。complete结果可附usage和model，它们只用于统计，宿主会在写入下一次模型消息前剥离；`rpen_route`仅用于识别推理所属的地址及模型，不发送到API。跨路由或模型不转发上个模型的私有推理字段。每轮统计额外记录配置方案和推理强度。

DeepSeek搜索使用`/v1/tools/search`（query/count/need_content），网页使用`/v1/tools/fetch`，query最多128字符；这些专用工具仅请求该服务，其他路由不隐式借用DeepSeek的Key。Key只在Authorization头。网页允许连接自定义HTTPS服务及本机HTTP接口，仍受服务CORS与浏览器混合内容限制；桌面通过专用IPC和Electron网络层转发，沿用系统代理。两端共用地址校验：HTTPS或回环HTTP、无URL凭据/查询/片段，接口路径限于聊天、模型列表和上述工具，禁止重定向，以免Key泄漏到其他地址。预设Base URL可修改以适配地域或工作区地址。此IPC不开放任意HTTP方法、请求头或文件系统。

401/402/429、超时、余额不足、截断/中断均提示，不自动重放已经完成的编辑；最大响应16MiB，单工具结果和上下文有界。停止后只保留完整工具轮次，旧计划不自动恢复。会话独立持久化；配置可调单次输出tokens、每任务最大模型请求轮数和自动压缩阈值。

网页请求使用当前浏览器的`fetch`，由浏览器应用其系统代理、扩展或PAC规则；网页不另建直连通道，也不能替浏览器配置系统代理。浏览器不向网页公开实际代理选择；网络、证书、代理、跨域等失败可能统一表现为`Failed to fetch`，此时保留原始原因与目标域名，并提示检查该域名的代理规则及CORS，不伪造HTTP状态或断言一定未经过代理。HTTP失败显示实际域名、状态码、服务`error.message/code`及可用的上游`metadata.raw`原因，SSE内返回的错误同样处理；完整正文保留在请求详情中并隐藏密钥。手动“获取模型”会显示失败原因，自动能力探测仍允许回退。

系统提示词位于src/core/agent-prompt.mjs，配置中可查看、修改和恢复。它包含音乐层次、拍数/延迟/倍率、音符与事件、父线锚点、噪域/全局事件、29种缓动、先读后写、必要参数询问、搜索引用核验、操作后验证、不绕过审批与不信任网页内指令。改提示词不能改执行层权限。

提示词还区分工作区状态、谱面数据、素材与偏好，明确导航、选中、修改及相对/绝对操作的边界。宿主在每轮实际注入工作区时间基准与命名实体摘要，名称可能是数字字符串，歧义须查询或询问；不凭上一次生成物件将导航误解为改物件时间。未自定义的旧内置提示词自动升级，自定义提示词保留，可手动恢复新版。

## 皮肤

编辑器皮肤API3新增ai-tool、ai-panel、tab-ai别名和ai页面。墨线将入口放在检查与协作。页签显隐由应用管理，皮肤需保留首次打开、换谱面与退出规则，并保持审批与停止按钮可见可操作。

自定义事件缓动字段 customEasing 的快照、裁切与 RPE 切碎规则见 ANIMATION-CURVES-PROTOCOL.zh-CN.md。通过事件 API 修改数值或曲线时保留未知字段；不可用 easingType 数字替代自定义曲线。
