# 自定义动画曲线 v1

普通事件、扩展事件、噪域数值事件、全局事件与着色器参数轨道共用同一求值规则。含自定义曲线的 Next 文件 META.RPEVersion 至少为 250；这是谱面格式版本，不改变编辑器程序版本。曲线仅在实际采样时编译，标准缓动保留原路径。曲线快照存于事件中，不依赖设备上的模板库。

## 数据

事件可包含 customEasing：

```json
{"curve":{"version":1,"name":"轻微回弹","nodes":[{"x":0,"y":0,"mode":"corner","out":[0.2,0]},{"x":0.7,"y":1.15,"mode":"smooth","in":[0.45,1.15],"out":[0.8,1.15]},{"x":1,"y":1,"mode":"corner","in":[0.9,1]}]}}
```

x 是事件持续秒数的归一化时间，y 是起终值的过渡进度；沿用现有事件的 TempoMap / bpmfactor 换算。不是直接按拍数线性插值，也不是“调速曲线”面板中的距离缓动。每条曲线 2–256 节点，首尾必须是 (0,0) / (1,1)，x 严格递增，y 允许超调与回退，绝对值不超过 10000。in / out 是绝对控制坐标，X 限制在节点与对应相邻节点之间，Y 同样有界。

模式 auto 自动决定切线，smooth 为对齐平滑，corner 的两柄独立；linear / hold 定义本节点至下一节点的线性 / 保持段。保持段在下一个节点时间跳到其值。smooth 对齐是编辑约束，播放器直接求实际控制柄。源定义、节点和事件上的未知字段在原生保存中保留。Schema 位于 schemas/animation-curve-v1.schema.json；相邻次序、首尾坐标与控制柄局部边界由运行时补充校验。

customEasing 优先于 bezier、easingType 和 easingLeft/Right。数值及颜色按曲线插值；文本沿用逐字和 %P% 语义；不插值的数据继续保持起值。普通、扩展、噪域、全局、着色器、取样及预览统一使用 event-easing.mjs。速度使用分段三次 Bezier 的解析积分 ∫Y(t)X'(t)dt，覆盖负速、BPM 变化、线倍率和零时长边界。编译按曲线对象弱缓存，并最多共享 128 条相同控制定义。

## 裁切与编辑

切分在 customEasing 中保存 domain:[left,right]，保留 sourceStart / sourceEnd 作为原数值基准。不得只把两端重归一化，因为两端可能同值而中间不平直。相邻切分段共享完整曲线快照，可在删除分界时恢复原区间。区间替换、文字排线和追踪工具也使用同一裁切规则。

修改源曲线保留 domain 和数值基准，同时重算事件边界值。属性编辑起终值会重算源数值映射；若裁切的两端进度相等，无法单独改出不同端值时明确拒绝，用户可同时改两端或重新调用模板。调用新的模板按当前事件的起终值重新应用完整模板。

一次拖拽或一次数值编辑作为一次撤销操作，支持 Esc 取消，预览不写历史。多选应用只复制曲线，不复制第一项的时间、数值、所属线或私有字段。绑定组同步曲线字段，切回标准缓动会移除 customEasing。未知提供方的全局事件继续只读。浮窗键盘路由只接管自身焦点，文本复制粘贴、撤销和删除不穿透到谱面；失焦取消拖拽，关闭清除观察器、帧任务和选择观察。首次撤销恢复原有标准缓动/Bezier 字段，多选撤销恢复每个目标的独立快照；失败的提交不进入浮窗历史。

控制柄转过本节点的垂直时间边界时，仅限制 X 并保留 Y，不把整条控制向量缩为零。对齐平滑模式先约束正在拖动的柄，再沿其反向对齐另一柄；遇到相邻节点的时间边界时沿原方向缩短。屏幕上不足 18 像素的柄以虚线与空心方柄提供独立命中位置；这是显示辅助，不改变保存坐标，点击不产生编辑，开始拖动后从可见位置调整。已保存的零长度柄也可通过该位置重新拉开。

## 编辑器内浮窗与模板

属性中的标准缓动与自定义模板为同级折叠组。曲线编辑使用编辑器内可拖拽、可调整大小的大浮窗，不创建浏览器或桌面子窗口。拖动标题栏移动，右下角调整大小，标题栏双击或四角放大按钮放大/还原。位置、尺寸、放大状态、时间区间、纵向尺度和吸附设置统一使用本地偏好服务，键为 rpen-animation-curve-view-v2。浮窗直接继承当前语言和皮肤。关闭后不调度帧或继续观察会话。主谱面或选择变化时禁止覆盖旧事件。

播放按钮与空格使用 animation-curve-preview.mjs 的共用时钟，曲线标点和谱面预览同步循环选中事件的秒数区间；每轮时长沿用属性草稿预览的 0.3–3 秒范围，裁切事件使用 domain 对应的源进度。普通、扩展、多线、噪域、全局及着色器参数分别提供有界的事件轨道预览快照，不复制音符数组，不写入会话、播放位置、音乐或撤销历史。快照只在开始或编辑时更新，逐帧仅读时钟。停止、失焦、选择失效、帮助及关闭释放预览状态；面板关闭时不引入持续取样。无可用接口时明确提示原因。

浮窗根据实际宽高调整字体、SVG 图标、控件、间距、属性栏比例和画布坐标标注，紧凑布局以浮窗本身尺寸触发。图标统一为 24 单位描边 SVG，继承皮肤颜色；选择、窗口放大/还原、适合曲线、模板另存/更新及文件导入/导出使用各自语义图形，按钮提供本地化悬停与无障碍名称。

V 选择、A 添加、D 删除工具，Delete / Backspace 删除内部节点；Shift 多选、框选；双击形状保持加点；拖曲线段调整弯曲；Shift 锁轴，Alt 断开控制柄；Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销重做，Esc 回退拖拽，空格预览，F 适合窗口，? / F1 详细帮助。滚轮纵轴缩放，Ctrl+滚轮横轴缩放，Shift+滚轮平移时间，中键或 Alt+空白处拖拽平移。文本输入保持原生快捷键。帮助内有平滑进出、轻微超调、先退后进、中途停顿、落地回弹和阶梯切换六组实例，均配有曲线、节点、控制柄和坐标图示，可直接载入并撤销。图示与载入内容共享同一份定义。帮助在浮窗内显示，不阻断编辑器其他区域。

模板库使用已有本地偏好服务，键 rpen-animation-curves-v1，最多 512 项。模板记录 id / name / curve，文件格式为 {format:"rpen-animation-curves",version:1,templates:[...]}，扩展名 .rpencurve，支持 JSON 导入。名称冲突保留双方并加编号。导入不覆盖旧库；名称编辑与更新只修改模板，事件始终持有独立副本。可把导入谱面的曲线另存为模板。模板或视图保存失败必须可见，不能自动清空旧库。

## 导出

RPEN / Next JSON / PEZ 保存完整定义，重新打开后可继续编辑；同内容定义在解析时共享对象，不形成外部依赖。RPE 默认将自定义缓动切碎成原生分段线性事件；保留事件未知字段，拆分绑定组解除以防碎片联动。内部按事件秒数切分，再转换为拍数。切分先覆盖所有节点，用三次 Bezier 控制包络约束整段误差，速度另约束每段积分与部分区间的累计距离。默认相对数值容差 0.001、距离容差 0.1；透明度等字段仍服从 RPE 自身的整数精度。文本为有界离散取样，过渡时刻误差控制在源事件持续时间的 0.00001 内。

每事件最多 8192 段，每次导出最多一百万事件；超预算明确失败，保留原谱面，不能输出缺失曲线。Hold 跳变必要时用 RPE 瞬时边界事件表达。关闭切碎而仍含自定义缓动时拒绝 RPE 导出。RPE 仍不支持噪域与全局事件，必须沿用原本的明确移除确认，不能把缓动切碎当作两个事件系统的兼容实现。
