# RPEN 视频渲染模块

唯一用户入口为顶部右侧 `#render-video`“渲染”按钮；在谱面库首页禁用，不增加卡片动作、侧栏、工具栏或快捷键入口。UI、场景和编码模块按需动态加载，不注册模组，也不使用全局 DOM MutationObserver。

## 数据和时间

`src/application/render-project.mjs` 从当前谱面捕获只读副本和素材引用。普通谱面采用完整 chart；超大谱面采用完整磁盘文档的 header、revision、区间 window、hits 和 soundNames。窗口不作为完整数据源，不展开重合组。磁盘 revision 改变时明确终止，不能继续混用两个版本。

画面、音符、打击音效和输出区间均使用**谱面秒**。音乐位置 = 谱面秒 + 有效 offset / 1000。修改面板中的偏移只改变音乐读取位置，不移动音符与打击音效。音乐时长扣除偏移后用于自动终点；明确的 `META.duration` 优先。无音乐时遍历音符、普通与特殊事件、噪域、全局事件的实际时间字段，排除遥远的状态延续哨兵时间。

窗口接口 `soundNames` 返回当前磁盘文档的去重音效名（包含 tap/drag/flick），最多 512 种，用于预先解码和计算音效尾音范围。`hits` 是谱面秒、半开区间，返回的 count 为实际重合数量。混音按 count 加权，不创建 count 个对象，不使用整段 8192 次截断。

## 参数和皮肤

`schemas/video-render-settings-v1.schema.json` 描述本机偏好。设置不写入谱面，不进入谱面撤销。区间打开时重置；其他偏好持久化于 `rpen-render-studio-v1`。任务开始时冻结参数，禁用参数表单，并独立创建最终分辨率的场景。实时预览的分辨率与输出分离，最大 1280×720。

`skinPolicy` 默认为 `render`：渲染器控制打击粒子，保留所选皮肤的音符和命中贴图。`skin` 尊重皮肤自身的粒子隐藏、时长、尺寸、旋转和着色规则。全局关闭打击特效仍优先；皮肤信息不会写回或临时污染编辑器共享记录。音效优先级为谱面同名素材、所选皮肤、内置声音；不借用编辑器的旧皮肤缓存。

默认渲染策略的打击粒子采用 PR #34 的参数：扩散半径系数 `1.1×0.85×1.3×1.03`、尺寸系数 `0.0907×1.05`，寿命 `2/3` 秒、数量 4；外扩采用 `render-particles.mjs` 的有理函数，透明度为 `1-progress`，从寿命的 40% 开始按 sine-in 收缩，幅度 `0.253×1.15`（29.095%）。命中贴图仍以音符尺寸的 1.4 倍绘制，默认 31 帧、每帧 0.015 秒，资源包动画沿用所选皮肤。渲染面板预览与视频导出共用这些参数，普通编辑器播放和 `skin` 策略沿用各自原有特效。保留现有完整命中枚举及批绘制，不引入模组旧版的固定数量截断。

打击特效与普通播放共用 `Preview.drawHits` 的命中枚举、位置缓存、视口裁剪和 GPU 批绘制。`render` 仅提供粒子外观、完整寿命及保守绘制半径；`skin` 直接沿用普通播放的皮肤特效路径。密集区间不按固定总数量截断特效，避免旧粒子占满名额、遗漏后续新打击；视口裁剪不得遗漏边缘仍可见的贴图或粒子，批绘制失败回退 Canvas 路径。

噪域在普通预览与视频渲染中共用 `previewNoiseGeometry`：中心按舞台横纵比例适配，角点相对中心先旋回局部坐标、按自身横纵轴缩放、再旋回，保持旋转角和矩形形状。之后再执行 `NoisePreview.transformGeometry`（如三维摄像机投影），不覆盖已有钩子；窗口外复用已变换几何时不重复缩放。噪域取样的轮廓、角点及事件值反算使用同一显示变换，锚点仍表示绝对舞台坐标；谱面本体的事件、积分及坐标语义不变。

`render-studio/noise.mjs` 只在渲染实例上启用 `NoiseSkinRenderer` 的 `overlay:true`，并为未指定皮肤的噪域层补入内置 NoiseField；补入信息仅保存在缓存的渲染副本，已有皮肤优先，不写入原谱面。overlay 保留一张原始场景纹理，计算皮肤结果与原图的 RGB 最大通道差，用 `smoothstep(0.003,0.022,delta)` 作为混合权重，再以预乘透明度叠加；小色差效果会被削弱。普通编辑器预览保持默认 `overlay:false` 的整帧替换，不使用颜色差过滤，也不自动补入默认皮肤。

## 编码与输出

Mediabunny 1.65.0 为未修改的官方 npm 浏览器模块，固定版本、来源、源码提交和校验值见 `assets/vendor/mediabunny/UPSTREAM.json`，MPL-2.0 及源码取得地址随程序分发。

`src/platform/video-encoder.mjs` 在逐帧前等待数据和资源就绪，按固定帧率写入，末帧缩短至所选区间终点。音频按最多一秒的 PCM 块混合，跨块保留音效尾部，按时间与视频交错写入；不分配整段离线混音或整段压缩视频缓冲。所选容器无法编码预期音频时明确失败，不能自动变为无音轨视频。

`src/application/render-frames.mjs` 负责跨平台帧调度。`CanvasSource.add` 同步捕获当前画布后，仅允许下一帧的绘制与当前帧编码重叠；下一次送帧仍须等待编码器和文件输出的背压，不累积帧队列。缺少同步 `VideoFrame` 快照能力时自动采用顺序绘制。分辨率、帧率、编码质量、所有帧时间戳、音效与混音算法保持相同；不通过改变编码器质量模式加速。

编码任务的 `drawFrame(time,index,frames,signal)` 只负责准备和绘制输出画布；独立的 `onFrame` 回调提供实际编码画布，面板预览和进度按墙钟最多约每 100 ms 更新一次（首尾必更新），不减少文件中的输出帧。不重复复制另一套试听画布。主线程按时间片协作让出：支持时使用 `scheduler.yield`，否则使用定时任务；Shader 的资源等待以实际截止时间判断，避免更快的任务调度造成假超时。取消或错误时中止并收回提前绘制，再释放场景。

桌面桥 `rpenRenderOutput` API 1 只向当前受信主窗口公开 `begin/write/close/commit/abort/openFolder`。begin 显示保存对话框，返回不可猜测的 token；write 为有界随机位置写入（每次最多 1 MiB）；close 刷盘但不覆盖原文件；commit 完成后原子切换。成功保存后，面板右下角显示“打开所在文件夹”；openFolder 只接受当前窗口最后一次成功保存的 token，由主进程打开记录中的目标父目录，不接受任意路径。打开失败明确提示原因。失败和取消删除任务临时文件，保留旧目标。导航、渲染进程退出或窗口关闭清理任务及已完成 token；每个窗口最多保留一个已完成结果。路径由原生对话框选择，不能由 write 请求指定。

网页优先使用 File System Access，缺省使用 OPFS 临时文件；不会退回整个文件的 BufferTarget。OPFS 结果发起下载后可再次下载，关闭时清理临时文件。网页仅报告“已发起下载”，不声称浏览器文件已落盘。输出选择取消、编码取消、保存失败和保存成功分开报告。

## 渲染扩展和清理

`src/ui/render-extensions.mjs` 提供 `registerRenderExtension(attach)`。attach 接收新预览器和 purpose（`autoplay` / `export`），返回幂等释放函数。三维摄像机复用此入口；原有两个编辑器实例保持原行为。渲染也调用 `preview:before` 和相应覆盖层，回调必须使用传入的 chart/seconds，离线导出不依赖实际播放头。

`Preview.dispose()` 解绑字体监听，释放批绘制、Shader 与噪域资源以及辅助画布。加载和渲染分别有 AbortSignal、代次和最终清理；关闭后不接受过期结果。静止关闭面板无采样、无播放循环。待渲染的音乐或音效缺失/解码失败必须有明确原因，不静默导出残缺声音。

实际能力依设备的 WebCodecs 编码器而异；能力探测不代替各平台实测。

## 着色器事件与自定义代码

效果事件遵循 Phira extra.json 的 `effects` 结构；`start/end` 是拍数三元组，`global` 为是否作用于 UI，`vars` 保存参数常值或缓动轨道。RPEN 保留 `line/order` 等已有扩展字段，参数时间沿用所属线倍率和真实秒缓动，不因格式统一而改变。

`assets/rpe/shaders` 仅保留 40 个 GLSL 源文件，接口统一为 GLSL 1.00 的 `uv/screenTexture/screenSize/time`。原 Cocos 顶点文件、重复 `_2` 文件与独立的 pr 目录已移除。旧 `_2`、clone 和数值类型编号只在输入兼容映射中保留，所属线的旧默认映射保持稳定，同类事件每次独立叠加。部分旧谱指定的 RPE 效果与原 portable 效果存在实际差异，因此单文件包含同接口的兼容分支；运行时按旧引用选择，在编辑器中保留原视觉与默认值，不重新维护两套文件。内置接口兼容参数仍按原逻辑分辨率求值；用户自定义源码的 `screenSize` 为预览输入画面的实际物理像素尺寸，排除编辑器为布局、比例适配保留的外围区域。`uv`、`gl_FragCoord` 与 `screenTexture` 统一在此输入画面内定位，像素坐标从该画面的左下角开始；完整向量和 `.x/.y/.xy` 分量一致，深度和 w 分量保留。普通预览、侧边画面、代码面板与视频渲染共用适配，不改源码或谱面参数，不增加截图、中间纹理或逐帧源码处理。自定义参数不采用颜色 0–255 的自动换算。

自定义代码以 `/资源根路径` 引用，开头斜杠具有 Phira 的资源根语义，不以扩展名限制所引用的文件；GLSL 文件常见扩展名 `.glsl/.frag/.fs/.fsh` 均可导入和选择。相对路径仅用于旧资料兼容，不通过同名文件猜测而跨目录取代码。资源文件优先于同名内置效果；旧 `/xxx_pr.glsl` 引用在未附带实际文件时仍可映射内置源。源文件最大 256 KiB，UTF-8；编写时使用 `void main()`，可动画参数为 float、vec2、vec4，在 uniform 声明同行用 `%数值%` 指定默认值。错误来源和编译错误明确显示，失败结果缓存，不逐帧重复编译；两个预览器共用当前谱面的通知去重，同一问题在关闭谱面前最多弹报一次，不因图片刷新或播放切换重新提醒。缺失 Shader 在基础谱面检查的素材问题中按引用去重列出，使用后台已有文件名索引与播放一致的路径规则，只在谱面／素材改变时重算，不在逐帧绘制中扫描或读取源码。导出视频不能静默略过失效 Shader。

通用模板库保存在本机设置 `rpen-shader-library-v1`，格式见 schemas/shader-library-v1.schema.json，最多 256 项、8 MiB。存储使用原有本地设置服务，保留并发修改检查；模板库不写入谱面。新建、导入 GLSL 和加载内置代码生成独立草稿，内置文件始终只读。通用模板应用时以来源身份和源码 SHA-256 生成 `shaders/custom/<hash>.glsl`，在 `#version` 后附加 `// @rpen-template {"version":1,"name":"原名","chart":"谱名前缀","origin":"library:ID","revision":"来源版本散列"}` 注释（非通用来源可省略 origin/revision），不扩展 Phira 事件格式。编辑器显示“原名 · 谱面名的前六个 Unicode 字符”，包内引用保持稳定。元数据随 GLSL 保存和导出，外部播放器忽略该注释；旧散列资源仅在当前通用库仍有相同源码时恢复原名，否则显示 Shader。重新应用同一版本通用模板会复用其已经编辑过的谱面副本；通用模板更新产生新快照，不改旧副本。

打开谱面资源直接进入“谱面共享副本”编辑范围，显示本谱面引用数量；保存替换同一路径源码，所有引用事件同步生效，参数轨道保留，不改通用库或其他谱面。Ctrl+S 按当前范围保存。普通本地谱面源码保存支持撤销/重做及写入冲突检测；超大谱与联机继续沿用原有素材保存规则，资源改动需要保存，且不纳入普通谱面撤销/自动联机传输。需要只改所选事件时，先复制为独立草稿，再应用；也可将谱面源码另存为通用模板。独立草稿应用继续通过事件事务、支持一步撤销。导入谱面自带源码只加入当前谱面资源，并显示范围提示。

代码窗口编译后检查共享副本已有引用的参数，删除定义或改变维数会显示提示；保存后基础谱面检查自动列出每个不匹配事件，不自动删除原参数。uniform 定义按源码字节对象缓存，仅在谱面或素材变化时提交精简定义给检查 Worker，不在绘制循环中读取源码。通用库按存储文本缓存验证结果。参数轨道只在谱面编译时排序并缓存拍数，播放二分取值；未变化的源码在无关图片刷新时复用，代码面板关闭后没有额外循环。

代码窗口由 `shader-tool.mjs` 按需加载，默认暂停。谱面场景使用独立 Preview，面板时间同时驱动判定线、音符、事件参数与 Shader；替换待编辑效果的源码及试调值，保留其他效果及普通／全局合成阶段，避免对已含该 Shader 的快照再次叠加。事件范围外或未选中事件时以独立全局试算显示草稿。也可切换独立测试图；测试图仅随 Shader 本身的时间逻辑变化。播放、手动时间和刷新均不移动主界面播放位置，不播放任何声音。超大谱使用独立、有界预览窗口，异步读取只保留一个请求并丢弃过期结果，不修改主预览和音效缓存。暂停后仅在输入、资源就绪或主动刷新时重绘，关闭释放独立场景和绘制资源。提供语法高亮、行号、查找、缩进、实时错误与参数试调；Ctrl+S 保存，Ctrl+Enter 编译，Ctrl+F 查找，Esc 关闭；取消直接丢弃尚未保存的代码、名称与试调参数并退出，已经保存或应用的内容保留，保存进行中暂不可取消。试调参数不写源码或事件。文本输入层保持透明，字符样式、内边距和边框与高亮层一致，避免皮肤的全局输入框与选中文字样式造成重影。窗口位置和尺寸保存于本机设置，关闭取消动画、编译延时、观察器与监听并释放 GPU 资源。图表切换或回首页会关闭窗口，选择改变后禁止应用到旧选择。未打开时不创建代码编辑器、预览循环或额外 GPU 上下文。

PEZ 导出先在导出副本中准备实际引用的内置扩展效果，生成可独立分发的 Phira GLSL 及根路径引用；原谱、素材和选择不改变。自定义文件作为普通素材随工程保存和恢复，通过原引用遍历筛选，默认不携带未使用源码，也不携带通用库的其他模板。旧内置基础效果仍按 Phira 内置名引用。代码资源不会覆盖包内已有不同内容文件。JSON 与贴图、音频一致，只保存资源引用；跨设备携带请用 PEZ。

## 编辑器整窗定帧录制

这是独立于 Autoplay 渲染面板的桌面播放渲染功能。默认 `EditorRecording = LEFTCTRL&LEFTSHIFT&U`，沿用快捷键设置与输入焦点保护。统一设置 `#editor-render-settings` 是默认折叠的 details，搜索命中时沿用设置搜索自动展开／恢复；`editorRenderFps` 为 1–240 的整数，默认 60，与普通界面帧率上限无关。`editorRenderAutoPlay` 默认 true。独立的按键显示设置 `keyDisplay` 默认 false，快捷键为 `KeyDisplay = LEFTCTRL&LEFTSHIFT&K`，进入原有快捷键编辑器，可单独修改。

播放渲染不切换当前编辑／预览模式，开始时按自动播放设置和原播放状态决定是否播放；关闭自动播放且原先暂停时保持静止，手动播放／暂停可继续同一段输出，暂停段声音为静音。到实际播放结尾或再次快捷键后封装并保存片段。循环播放在此模式不回跳；跳转、修改谱面、改变倍速、声部混音或音频设置仍会结束此次片段。启用按键显示时叠加层与其他软件 UI 一同进入完整客户区视频。

`src/ui/editor-recording.mjs` 为轻量入口，任务启动时才动态加载控制器、音频、捕获与编码模块。播放渲染由 `src/application/editor-frame-clock.mjs` 临时安装帧时钟，普通 RAF 在此期间不推进主画面；播放时每帧前进 `倍速/目标帧率`，暂停时不前进。`RecordingPlaybackAudio` 记录播放／暂停分段，将输出帧时钟映射回音乐时钟。捕获或编码变慢只延长生成时间，不省略输出帧。退出恢复音频方法、时钟、动画和背景节流设置，停留在片段终点；取消保存选择恢复原播放状态。

`rpenEditorCapture` API 1 提供 `call('begin', {raw:true}) → {ok,result:{id,format,fence}}`、`call('frame', id或{id,fence}) → {ok,result:{width,height,format,stride?,bytes}}` 与 `call('end', id)`。桥仅允许受信主窗口主 frame，token 属于当前任务，单次只允许一个截图请求。优先返回客户区原始物理像素 BGRA/RGBA，按任务用已知颜色探测本平台位图格式，不根据系统名称猜测；未知格式或旧桥回退无损 PNG。不包括操作系统标题栏、鼠标指针和原生菜单；不缩放或重建 DOM，不改变皮肤和普通预览特效。原始像素直接构造 `VideoFrame` 送 `VideoSampleSource`，绕过 PNG 压缩／解码及中间画布。预载的可选 `requestFrame(requestId,value)` 使用消息转移帧 buffer，避免 contextBridge 再次深拷贝；接收监听仅在录制任务存在，支持引擎还会将 buffer 所有权转给 VideoFrame。旧桥保留 `call('frame',id)` 兼容路径。像素预算 32 Mi pixels，单帧上限 128 MiB；尺寸／DPI 变化结束并保存此前片段，不拉伸画面。主进程在导航、崩溃或退出时恢复捕获状态。

录制状态按钮底部的紧凑像素进度条同时携带帧标记：每次完整画面绘制后更新，主进程只接受与当前标记一致的合成结果。旧表面立即丢弃并重取，不作为输出帧，也不改变音视频时间戳。最多保留当前截图，无后台截图队列；超过 5 秒仍未完成合成会明确失败并恢复。皮肤隐藏状态条时回退等待绘制提交。新模块的加载、帧标记、像素格式探测、消息监听与图像资源均只在录制期间存在。

`createVideoEncodingSession` 采用增量封装，视频时戳为帧号/目标帧率，每帧时长固定。音频按至多半秒读取及交错写入，最终按实际帧数收尾，不预先分配整段音频或视频。优先 MP4，奇数窗口尺寸或编码能力不满足时使用 WebM，始终保留原像素尺寸；无可用音视频编码器则明确失败。文件输出复用原子 `.part` 写入，失败保留旧文件。

音频复用当前 `playbackBuffer`（含选中声部混音）、音乐与音效音量、每类音效延迟、当前线静音策略及皮肤音效。判定点按音乐时钟转换，音效样本保持原速；不保调的倍速采用采样率转换，保调倍速采用有界 WSOLA，保留音高，但不保证与各平台实时媒体保调算法逐样本相同。超大谱音效继续按磁盘索引短段读取；录制每帧等待可见编辑页与预览窗口就绪，不能仅录制缓存缺页画面。录制过程中修改或切换谱面会结束片段，避免音画来自不同文档。

皮肤别名 `@editor-recording-status` 和 `@editor-render-fps` 对应按需状态控件与帧率设置。录制关闭时无编码器、截图、音频转换、动画遍历或额外定时器；主循环只检查是否正在录制。Electron 的 Windows/macOS/Linux 共用捕获代码，平台实测分别记录；网页无法保证等价整窗离线捕获时明确提示，不退回实时掉帧录屏。

### 独立按键显示

`src/ui/key-display-tool.mjs` 为轻量入口，仅启用时动态加载 `key-display.mjs` 与键帽状态，关闭后移除全部键帽、DOM、动画帧和失焦监听。复用软件已有输入入口，不拦截或重演编辑操作，不读写磁盘日志、整谱缓存或音频设备。

键帽显示最近按键组合、鼠标按钮与滚轮，连续重复合并计数；右下角顶层叠加向上浮动，按距离和寿命淡出，队列有界。密码／显式私密区域与 IME 未完成状态不显示。开关本身不作为操作记录展示；真实文本输入不穿透成谱面快捷键。普通使用仅在有键帽时动画，队列清空后停止；播放渲染时改用输出帧时钟，结束后恢复，避免编码速度改变键帽寿命。

播放渲染不调用 getUserMedia/getDisplayMedia，不申请麦克风、系统录音或桌面音频权限。只离线混合编辑器当前音乐／声部与打击音效。
