# 声部分离使用指南

入口：**谱面工具 → 音频分析 → 声部与分析音源**。不需要 AI API Key。

## 桌面端

1. 打开需要处理的谱面，确认原音乐可播放。
2. 首次打开音频分析时，阅读磁盘占用提示，并选择音频工具存放位置；建议使用空间充足的非系统盘。取消选择不会开始安装或分离，也不会静默选择系统盘。随后点击 **一键准备分离环境**，一般选 **安装（CPU）**，有兼容 NVIDIA 显卡时可选加速版。
3. 等待下载、安装、检查完成。不需要预装 Python、输入命令或修改 PATH。下载失败后可以重试；详情中保留安装日志。
4. 点击 **分离当前音乐**，默认四声部。首次下载模型，后续可复用。
5. 勾选人声、鼓、贝斯等音源，至少保留一项。编辑器播放按钮会播放所选声部的混合；倍速、保调、定位、暂停和继续均可用。波形/频谱以不同颜色并排显示各项，AI 未指定音源时分析当前混合。

四声部包含人声、鼓、贝斯、其他配器；六声部另含吉他、钢琴，但仍可能串音。模型和依赖不随桌面包捆绑，首次使用需要网络和数 GB 可用空间。CPU 较慢，支持的 NVIDIA 设备可加速。分离过程和音频留在本机。

| 平台 | 操作 |
| --- | --- |
| Windows x64 | 一键准备，CPU 或 NVIDIA 加速 |
| Apple 芯片 macOS | 一键准备，选择 CPU |
| Linux x64 | 一键准备，CPU 或 NVIDIA 加速；需满足预编译依赖的系统要求 |
| Intel macOS / ARM Linux / ARM Windows | 当前没有完整的一键依赖组合；使用配置好的 Demucs 环境，或导入外部分离结果 |

一键安装会按平台显示支持情况。Windows x64 的全新安装与分离经过实测；其他列出的一键平台已核对依赖与下载目标，仍需对应平台实测。不能把“桌面包可启动”视为所有音频推理库均可安装。

首次使用前必须由用户选择位置，三套工具的新安装环境、Python、模型和结果均使用所选文件夹下的 `RPEN-Audio`，本机用户数据目录只记录位置。模型和环境可能占用数 GB 至数十 GB，结果与下载缓存还会持续增长。通过 AI 或其他入口发起安装、选择环境或生成本机分析任务时，也会进行同一位置检查；并发请求共用一次引导。位置设置按本机保存，不随谱面改变。更新或移动编辑器不会要求重新安装。安装成功并通过检查后才切换环境配置，失败时保留原有配置。新建的 Python 只供本功能使用，不注册为系统 Python。

升级前已有运行环境的用户同样需要确认存放位置；已有环境保留原位，模型和缓存迁往所选位置。此前已经通过目录管理完成选择或迁移的用户无需再次选择。

### 模型与缓存位置

桌面端点击 **模型与缓存位置…**，可分别打开声部分离、起音检测、AI 节奏生成的模型、结果缓存、下载缓存或工具数据目录，也可查看运行环境位置。

首次尚未设置时，可在此点击 **选择存放位置…** 重新打开引导。设置完成后，点击 **迁移模型与缓存…** 并选择目标文件夹，经确认后在其中新建 `RPEN-Audio`。迁移涵盖三套工具的模型、结果、安装下载缓存、推理缓存和临时数据，后续下载与处理使用新位置；位置随本机保存，重启或更新后继续使用，不写入谱面。已有 Python、虚拟环境、源码及其配置保留原位，避免破坏路径依赖。

迁移期间禁止启动安装、分离或检测；已有任务未结束时不可迁移。迁移前检查剩余空间与目录关系，拒绝覆盖已有的 `RPEN-Audio`，不跟随目录链接或指向数据目录外的文件链接。新副本逐文件校验并完成持久配置切换后，才逐一删除仍与已校验副本一致的原文件；上述数据子目录以外的文件和发生变化的原文件保留，不递归删除原工具目录。复制、校验或配置写入失败时继续使用原目录，未完成的副本保留并报告位置。切换后清理失败不影响新位置，界面会提示遗留原缓存。中断后以持久配置为准；配置指向的磁盘不可用时提示错误，不静默改回系统盘或重新下载。

### 全局缓存清理

音频分析页面的 **清理音频缓存…** 或目录管理中的 **清理全部音频缓存…** 都会先显示确认框。确认后清理三套工具为**所有谱面**保存的分离结果、采音结果、安装下载缓存、推理缓存和临时文件，也检查已知运行环境目录中的遗留缓存。保留已下载模型、Python 环境、源码、谱面和原音乐；用户自行导入的声部也保留。当前会话恢复原音乐播放，移除派生分离音源，清除采音预览及内存中的分析缓存，需要时重新分离或采音。清理下载缓存后，后续更新环境可能需要重新下载安装包。

存在安装、分离或检测任务时拒绝清理；清理和迁移不能同时运行。仅处理明确的缓存子目录，不递归删除工具根目录，也不跟随指向其他目录的链接。被占用、发生变化或无权限的文件会保留并报告，不影响模型和原始谱面文件。

### 已有环境

展开 **分离选项与高级环境设置**：

- **重新检测**：检查当前环境是否可用。
- **选择已有环境**：选择已经安装 Demucs 4.1 的 Python 可执行文件，检查通过后使用。
- **用已有 Python 安装**：有 Python 3.10–3.12 时可手动指定基础解释器，编辑器仍在独立虚拟环境安装依赖。
- **清理分离结果缓存**：删除派生结果，保留模型和环境，原音乐与谱面不变。

自备环境的 Python 必须在更新编辑器后仍然存在。不要选择另一个软件解压目录中随时可能被删除的临时 Python。

## 网页端、手机和平板

目前网页端提供声部导入与后续分析，**不在浏览器内直接运行 Demucs，也没有自动上传音乐的云分离服务**。

最简单的流程：

1. 在 RPEN 桌面端打开相同音乐并完成分离。
2. 点击需要保留的声部右侧的 **导出**，保存 WAV。
3. 将 WAV 传到使用网页的设备。
4. 在网页端点 **导入声部**，可一次选择多个音频文件。
5. 勾选一个或多个声部，使用编辑器播放按钮播放，同时查看彩色波形/频谱或进行 AI 采音。

也可以使用已安装的 UVR、Demucs 或其他分离工具导出结果再导入。没有桌面电脑时，先通过另一设备或自行选择的工具获得声部文件；RPEN 不内置第三方云上传流程。

网页端不需要安装 Python。DDC、Mapperatorinator 等本机模型仍只通过桌面端启动；网页端的频谱分析和采音可以处理已导入声部。

## 对齐与保留结果

- 所有声部与原音乐共享起点和谱面延迟，不另设声部偏移。导入同一首完整音乐的分离结果，不要裁掉开头静音、变速或使用不同版本音乐。
- 较短的声部在结尾补静音，过长的部分不延长编辑器时间轴。声道或采样率不同的文件按原音乐时间轴重采样、混合，不移动音符或修改谱面延迟。
- 分离和勾选不会替换素材库中的原音乐。勾选会临时改变实际播放音源；退出谱面后恢复只播放原音频，选择不持久化。
- 声部列表属于当前音乐的分析会话，换音乐或重启后需要重新导入，或再次分离相同音乐以复用本机缓存。
- 再次分离成功后整组替换当前会话中所有 `kind:separated` 条目，不按模型追加；同模型或不同设备/参数重做也使用新结果。原音乐和 `kind:imported` 条目保留。同类试听声部按 stem 映射至新结果，不存在的声部移出，空选恢复原音乐；新结果、必要的解码及试听准备就绪后才切换。失败、取消或迟到的结果不改旧列表与播放选择。旧混音缓存失效，旧音高/采音预览按来源引用及修订失效。磁盘中的可复用分离缓存仍按原存储管理规则保留。
- 声部不写进谱面 PEZ。需要长期保留或在另一设备使用，请导出 WAV。
- 同一谱面内，近期使用的声部组合会缓存混音与播放准备结果，切回时复用；缓存按容量淘汰，退出谱面、更换音乐或移除相关声部后清理或失效，不写入谱面文件。
- 波形按每个显示行覆盖的完整时间区间取峰值，避免短音频滚动时因跳点采样而闪动，并复用多级峰值索引。波形/频谱只绘制有效区域，静止画面复用；定位、缩放、窗口大小、颜色或透明度变化时及时刷新，不降低可见范围的显示精度。

## 显著音高

音频分析页的“显著音高”支持一个分离或用户导入声部。音高目标与试听多选独立，不替换原音乐或改变当前混音；同一时间只保留一个目标声部和一种显示位置。切换目标取消过期结果，移除、替换目标或更换音乐后关闭。声部选择不跨音乐会话保存，显示位置与显示设置保存在本机的 `rpen-audio-pitch-view-v1`，旧音域/位置偏好保留，其余新增项使用默认值。

- 原位模式替代目标声部的波形/频谱栏；目标未勾选试听时临时增加该栏，其他已选声部保持原图。
- 右侧模式使用整个事件区宽度，作为事件下方的透明衬图，保持音符区波形/频谱。使用与原分析图相同的底层绘制关系，画布不命中鼠标；保留事件显示、选择、放置、删除、粘贴、拖动、多选控制球及快捷键，不清空选择、不产生撤销记录。仅音符编辑或其他专用编辑/预览模式暂时隐藏，恢复后继续显示。
- 时间纵向排列，与原音乐起点、META.offset、BPM、判定线倍率和滚动缩放统一映射。横向以 MIDI 半音间距排列，保留浮点音高和滑音；C 音提供音名标注。只有原位模式通过音符画布的非阻断悬停显示音名、频率、拍数；右侧模式不注册事件区的音高悬停监听，不改写事件画布原有提示。
- 显示设置默认折叠：`followWaveform:false`、`threshold:0.2`、`opacity:0.6`、`lineWidth:4`、`showGrid:true`；阈值范围 0.05–1、不透明度 0–1、线宽 1–10 CSS 像素。默认不按波形衰减；开启后不透明度乘以对应时间区间的归一化波形包络，再应用音频画布皮肤透明度。包络仅开启时计算并复用，关闭时取消计算并释放该图持有的包络，不增加模糊或发光绘制。
- 音域自动适配全曲默认有效候选；两端滑条显示音名、八度及 Hz，拖动进入手动模式并立即重绘，最小跨度为一个半音。范围外不绘制、悬停也不报告隐藏的音高。自动模式下控件值及时同步至实际显示范围，不显示与图形不同的旧默认值。
- 显示设置中的“重置设置”恢复默认阈值、不透明度、线宽、波形透明度开关、参考线及自动音域，保留当前声部与显示位置。原控件和折叠状态保留，重置即时重绘并持久保存；取消额外包络计算，不重新推理、不清空音高缓存、不创建谱面撤销记录。
- Basic Pitch 的复音候选压为单一显著音高，以短时连续性减少近似候选抖动；不确定、静音及无明确音高处留空，明显换音断开连线。保留置信度至少 5% 的候选供显示调参，默认只绘制至少 20%，保持旧默认连续性和八度修正条件；阈值越高只减少可见帧。算法缓存键升级为 `basic-pitch-1.0.1-dominant-v2`，旧结果首次需要重算，之后阈值/音域/透明度等调节均不重新推理。不是完整转谱或保证正确的主旋律提取。
- Basic Pitch 1.0.1、TensorFlow.js/WASM 4.22.0 随程序本地提供（Apache-2.0，详见 NOTICE 和 assets/vendor/basic-pitch）。仅开启时创建一个单线程 Worker，不使用渲染 GPU；可见时间附近优先，每块核心 4 秒、前后各 0.5 秒上下文，原音乐不整体复制或传出。每次推理释放临时张量，完成、取消、切源时终止 Worker。
- 当前最长支持 30 分钟；轨迹缓存最多 4 项且合计不超过 8 MiB，持久结果缓存最多 32 项且不超过 32 MiB，以完整音频内容、采样率、声道、算法/模型版本识别。桌面结果位于 `起音检测/cache/pitch-v1`，使用已有位置设置、迁移、清理与互斥协议；网页使用 `rpen-audio-pitch-v1` IndexedDB。缓存失败保留当前结果并提示，下次可能重新分析。
- 原位/右侧切换、绘制阈值、不透明度、线宽、参考线、音域、BPM、延迟及判定线倍率变化仅重绘，不重新推理。绘制只遍历可见时间段，静止图复用；关闭后没有推理或新增后台任务，不写入谱面与撤销历史。

## 遇到问题

| 表现 | 处理 |
| --- | --- |
| 下载失败 | 检查网络和磁盘空间，再点一键准备；安装详情可查看具体原因 |
| GPU 不可用 | 选择 CPU，或确认使用 NVIDIA 加速环境且驱动兼容 |
| 提示环境不完整 | 重新准备，或选择正确的已有 Demucs 4.1 环境 |
| 分离时间较长 | 留在页面等待，可取消；六声部与整首长音乐可能更慢 |
| 声部与音乐不同步 | 核对是否为同一首完整音乐，是否裁掉开头或另行变速；所有声部共用原音乐起点 |
| 只播放原音频 | 分离后勾选需要的声部，再取消原音频的勾选；至少保留一项 |

声部分离与采音检测是两个步骤。分离环境准备完成，不代表其他模型环境也已经安装；界面分别显示其状态。
